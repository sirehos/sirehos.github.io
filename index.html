Our history, purpose and direction

Every release has a name. Every name has a story.

🌱 Where SirehOS began

SirehOS takes its name from sireh, the Malay word for betel leaf, with a personal connection to Kebun Sireh in Penang, Malaysia. It began as an independent passion project: a wish to make infrastructure troubleshooting more approachable, portable and useful.

Our first release family follows the language of growth. Benih means seed: a small beginning with room to grow.

🧭 Our mission and vision

Mission: Build practical, transparent and safety-first tools that help people understand their systems, diagnose problems and learn by doing.

Vision: Grow an international open-source community where engineers, students, educators and curious newcomers can contribute tools, exchange knowledge and build useful technology together.

“A seed does not need to be big to grow into something meaningful.”

SirehOS Lite is not trying to be another everyday Windows replacement. Think of it as an infrastructure Swiss Army knife you can carry on a USB drive. The goal is original, integrated troubleshooting workflows—not merely a collection of unrelated utilities.

🔐 Verify your download

Compare the SHA-256 checksum of your downloaded ISO with the checksum on the official Beta 4 release. The values must match exactly.

Linux
sha256sum SirehOS-Lite-1.0-Benih-Beta4.iso
Windows PowerShell
Get-FileHash .\SirehOS-Lite-1.0-Benih-Beta4.iso -Algorithm SHA256

Run the command from the folder containing the ISO, or provide its full path. A checksum verifies integrity, not overall software safety.

Getting started

Turn the ISO into a bootable USB.

You cannot make a bootable USB by copying the ISO file onto a drive as a normal document. Writing an ISO image replaces the USB's existing contents. Back up your files first.

🪟 Windows: Rufus

1. Download the ISO from the official SirehOS release page and verify its checksum.
2. Download Rufus from its official site. Insert an empty USB flash drive (8 GB or larger is a practical starting point).
3. In Rufus, select the correct USB device and choose the SirehOS ISO under Boot selection. Keep the suggested settings unless the release notes specify otherwise.
4. Select START, read any image-writing prompts carefully, and confirm only after checking the USB device. All data on that USB will be erased.
5. Restart your computer, open its boot menu (often F12, F9, Esc or another vendor-specific key), and select the USB drive.

🐧 Linux: Ubuntu, Debian, Fedora and Red Hat

The same Linux imaging method works across these distributions. Identify the removable drive using:

lsblk -o NAME,SIZE,MODEL,TRAN,MOUNTPOINTS

Unmount any mounted partitions on the selected USB first. Then write the ISO to the whole USB device, not a numbered partition:

sudo dd if="/path/to/SirehOS.iso" of=/dev/sdX bs=4M status=progress conv=fsync
sync
Danger: /dev/sdX is a placeholder, not a command to run unchanged. Replace it only after positively identifying your USB drive. Choosing your internal disk will destroy its data. NVMe/USB naming can differ. Do not use /dev/sdX1 (a partition).

After writing completes, safely eject the drive and use your computer's firmware boot menu to start SirehOS.

Boot behavior varies by firmware, Secure Boot configuration and hardware. Beta testers should try a spare machine or virtual machine first. SirehOS does not need to be installed to the internal disk.
